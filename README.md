☕ Cafe Sales Analysis

📌 Project Overview

This project focuses on analyzing cafe sales data using Python. The main goal is to understand product performance, revenue, customer preferences, and sales trends.

🎯 Objectives

- Understand the cafe sales dataset.
- Clean missing and invalid values.
- Analyze item-wise sales.
- Identify monthly sales trends.
- Analyze payment methods and locations.
- Generate useful business insights.

📊 Dataset Information

- Total Transactions: 10,000
- Original Columns: 8
- Columns After Feature Creation: 10
- Date Range: 2023

Dataset Columns

1. Transaction ID
2. Item
3. Quantity
4. Price Per Unit
5. Total Spent
6. Payment Method
7. Location
8. Transaction Date

New Columns

- Month
- Day Name

🛠️ Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

🧹 Data Cleaning

- Replaced UNKNOWN and ERROR values.
- Handled missing values.
- Converted numeric columns into proper data types.
- Filled missing numerical values using median.
- Checked duplicate records.
- Converted transaction dates into date format.
- Recalculated Total Spent using Quantity × Price Per Unit.

📈 Exploratory Data Analysis (EDA)

The following visualizations were created:

1. Item-wise Sales Analysis
2. Monthly Sales Trend

4. Location-wise Sales Analysis

📌 Key Results

- Total Sales: 89,481.50
- Average Quantity: 3.03
- Average Price Per Unit: 2.95
- Average Transaction Spend: 8.95
